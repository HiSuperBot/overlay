# Repository guidelines

- Write all README files, documentation, and code comments in English.
- Keep native iOS application code under `apps/ios`.
- Focus on source changes. Do not start full Xcode builds, simulator sessions, or device runs unless the user explicitly requests them.
- Lightweight source and configuration checks are appropriate. Ask the user to perform build and runtime tests when needed, and give a short, concrete checklist.
- Keep generated build products and personal Xcode state out of version control.
